# 9/11 Interactive Archive

A research-first project for building a trustworthy, explorable map and timeline of publicly available September 11, 2001 media, testimony, events, people, and places.

The project is intentionally split into two concerns:

- **Archive Workbench** — ingest, normalize, deduplicate, geolocate, synchronize, source, review, and improve historical records.
- **Public Explorer** — a map + timeline interface for exploring synchronized photos, video, audio, testimony, people, places, and story threads.

The guiding principle is simple: **never replace the source record with an AI guess.** Raw source metadata remains immutable; derived claims carry evidence, uncertainty, provenance, and review history.

See `docs/PLAN.md` for the implementation roadmap and `docs/DATA_MODEL.md` for the initial data model.
